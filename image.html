接口配置
gpt-image 系列接口要求 images[] 数组（image_url）；Seedream / Ark 用 image 字符串。报 images[].image_url is required 时切到「images[] 数组」。
如 seed、watermark、guidance_scale 等，按接口文档填写。
代理与数据
最终请求地址 = 代理前缀 + 请求地址 + 路径。接口未开放 CORS 时使用。
接口约定
生成：POST {base}{生成路径}
编辑：POST {base}{编辑路径}
聊天：POST {base}/chat/completions

请求体（JSON 模式）
model / prompt，编辑时追加图片与可选 mask（gpt-image 以透明区表示修改区）。
Seedream/Ark：image / mask 传字符串；gpt-image 系列：images[] 数组（image_url）。用「编辑图片字段」切换。

API Key 与配置仅保存在本机浏览器（localStorage），不会上传到任何服务器。请确认目标接口已开放跨域（CORS）；否则配置代理前缀。
